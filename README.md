# EE5127 Internet of Things laboratories

This repository contains practical laboratory guides for EE5127 Internet of Things, an MEng Electronic and Computer Engineering module at the University of Galway. The labs develop a sensor-to-gateway-to-cloud system and encourage students to test behaviour, interpret measurements and make engineering decisions.

The sequence begins with CircuitPython on an Adafruit Feather nRF52840 Sense, sensor data acquisition and Bluetooth Low Energy. Later activities use a Raspberry Pi or ROCK 4C+ gateway, MQTT, Azure services, machine learning and Grafana. The guides are unassessed and introduce CircuitPython and Python concepts as they are needed.

**[Read the published lab guides](https://adnanelahi.github.io/ee5127-iot/)**

The published website is built from [`docs/`](docs/). Individual lab guides are in [`docs/labs/`](docs/labs/), with reusable setup and recovery information in [`docs/support/`](docs/support/). Labs and supporting files appear on the website as they are released.
