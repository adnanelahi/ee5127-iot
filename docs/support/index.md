# Support Material

Each lab contains its essential setup and practical steps. Use these supplementary pages when you need additional reference or recovery help.

- [CircuitPython Board Reference and REPL]({{ '/support/circuitpython/' | relative_url }})
- [Raspberry Pi Headless Setup and Recovery]({{ '/support/raspberry-pi/' | relative_url }}): imaging, SSH, WayVNC and TigerVNC desktop access, and VS Code installation on the Pi.
- [ROCK 4C+ Gateway Setup]({{ '/support/rock-4c-plus/' | relative_url }}): kit assembly, image installation, Bluetooth checks and TigerVNC desktop setup.
- [Azure CLI on Your Computer]({{ '/support/azure-cli/' | relative_url }}): install the CLI, sign in and select your Azure for Students subscription.
- [Monitoring Azure IoT Hub]({{ '/support/monitor-iot-hub/' | relative_url }}): use Azure IoT Explorer or Azure CLI on your computer to view incoming messages.

For BLE device advertising and services, see [Lab 3]({{ '/labs/ble-telemetry/' | relative_url }}). For gateway scanning and collection, see [Lab 4]({{ '/labs/rpi-ble-data-collection/' | relative_url }}).
